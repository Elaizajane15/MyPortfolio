# Elaiza Jane R. Moreno — Portfolio

My personal portfolio website, built with React and Vite. It introduces who I am, my skills, education, certifications, and projects, and gives visitors a direct way to reach me.

## Sections

- **Home** — introduction with an animated title and a running list of my skills
- **About** — background and what I bring to a team
- **Skills** — organized by category: Programming & Development, Frameworks & Technologies, Project Management, Technical & Computer Skills, and Soft Skills
- **Knowledge** — areas I've studied and practiced
- **Education** — B.S. Information Technology, Cebu Institute of Technology University
- **Certifications** — AWS Cloud Foundations, Cloud Architecting, and Generative AI Foundations badges
- **Projects** — selected work
- **Contact** — WhatsApp, email, and social links

## Built With

- React 19
- Vite
- React Router
- Tailwind CSS and custom CSS

## Running Locally

You need [Node.js](https://nodejs.org/) installed.

```bash
cd MyPortfolio
npm install
npm run dev
```

Then open the address Vite prints (usually http://localhost:5173).

To make a production build:

```bash
npm run build
```

The finished site is written to `MyPortfolio/dist`.

## Editing Content

Most of the text on the site — skills, education, knowledge, projects, and social links — lives in one file: `MyPortfolio/src/data/portfolioData.js`. Update it there and the pages pick up the change.
